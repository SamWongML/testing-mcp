**Handoff notes (P9 — 2026-07-24):**

- **Shape.** P9 is the agent-facing layer: the deterministic Insomnia→IR scaffolder (`atp import`),
  the golden-master parity helper, the five MCP workflow prompts, `MIGRATION.md`, and the finalized
  `CLAUDE.md` surface reference. No engine/schema/store changes — purely additive on top of P8.

- **Files:**
  - `packages/cli/src/import.ts` — `importInsomnia(yamlText) → { files, mapping }` (pure transform)
    + `writeImport(yamlPath, root)` (the CLI command layer: read → transform → write drafts +
    `MIGRATION.md`) + `renderMigration(mapping, source)`. Parses **Insomnia v5 YAML**
    (`type: collection.insomnia.rest/5.0`) via the new `yaml` dep on `@atp/cli`.
  - `packages/cli/src/golden.ts` — `goldenAssertions(baseline) → DeclarativeAssertion[]` (status +
    per-scalar-key shape) + `renderAssertions()` (TS source to paste). §19 step 4.
  - `packages/cli/src/__fixtures__/petstore.insomnia.yaml` — a representative v5 export exercising
    request→test, folder→suite, env, bearer auth, and a `{% response %}` response-ref tag.
  - `packages/cli/src/index.ts` — the `atp import <insomnia.yaml>` dispatch case + usage.
  - `packages/mcp-server/src/prompts/index.ts` — `registerPrompts(server)`: the five prompts, each
    an argument schema + an instruction template rendered over the real tool/CLI surface. Wired
    unconditionally into `buildMcpServer` (prompts are pure guidance, so they exist on the sync
    surface too — not gated on `ctx.db`).

- **§13.1 mapping the importer implements** (the *clean, deterministic* parts):
  request → a `defineTest` step · folder/`children` → a `defineSuite` with an inline node per child ·
  `environments.data` → `tests/_shared/env/<domain>.ts` (`defineEnv`) · bearer `authentication` →
  `tests/_shared/auth/<domain>.ts` (`bearerAuth`) + `request.authRef` · `{{ _.var }}` → `{{env.var}}`
  (auth token → `{{secrets.<VAR>}}`) · JSON body text → an object literal. Names slug to
  `<domain>.<name>` ids; the returned `mapping` (Insomnia meta-id → IR id, `<suiteId>#<nodeId>` for
  suite nodes) becomes the `MIGRATION.md` table.

- **The "messy remainder" is deliberately deferred to the agent** (the plan's design): an Insomnia
  `{% response ... %}` chaining tag becomes an `__TODO_CHAIN__` placeholder plus a `// TODO(migrate)`
  comment pointing at the `import_insomnia_collection` prompt. The scaffold **compiles** as-is; the
  agent wires the real `extract` + `{{nodes.X.var}}` + `needs`. Every generated request also carries a
  placeholder `assert: [{ path: "status", op: "lt", value: 500 }]` for the golden-master step to refine.

- **`regenerate_reports` is prompt-only, by decision (confirmed with the user).** `get_report`
  already re-renders any stored run into any format, so the prompt just drives `list_runs` →
  `get_report {runId, format}` over historical runs — no new tool, keeping the surface minimal.
  Documented as such in the prompt itself.

- **Testing posture — all real red→green, fully offline.** `import.test.ts` (7): per-slice mapping
  assertions **plus a compile round-trip** — it writes the generated drafts into a throwaway corpus
  *under repoRoot* (so `@atp/engine` resolves) and runs `compile()`, proving the drafts normalize into
  manifest entries (the P9 exit criterion, automated). `golden.test.ts` (4). `prompts.test.ts` (5):
  in-memory SDK client `listPrompts`/`getPrompt` with argument interpolation. `index.test.ts` (+2):
  `atp import` dispatch writes files + `MIGRATION.md`. Gate: typecheck / lint / test (356 passed |
  37 pg-gated skips) / compile all green. No DB needed for any P9 test.

- **Gotcha for the next session:** `atp import` writes under `process.cwd()`. Do **not** run
  `pnpm atp import <fixture>` from the repo root during dev — it scaffolds `petstore` drafts into the
  real `tests/` corpus (making `compile` report 5 entries instead of 3 and failing `commands.test.ts`).
  The tests always target a throwaway root. If you see stray `tests/petstore/` + root `MIGRATION.md`,
  that's the cause — delete them.

- **Review (P9 — 2026-07-25): completeness + simplicity (2 subagents, code-review skills).** The
  completeness reviewer probed the importer with adversarial fixtures the committed `petstore`
  collection didn't cover and found **1 Blocker + 4 Majors — all fixed** (each with a new regression
  test in `import.test.ts`):
  - **Blocker:** a folder whose only children are *folders* (nested-only) produced `nodes: {}` →
    `defineSuite` rejects it → `compile()` fails, breaking the exit criterion. Fixed: `collectRequests`
    depth-first flattens every descendant request into the nearest suite; a folder that flattens to
    zero requests is skipped (never an empty suite). New test also compiles a nested collection.
  - **Major (silent data loss):** colliding name-slugs clobbered files / collapsed node keys. Fixed:
    `makeUniquifier` dedupes entry ids collection-wide and node keys per-suite (`x`, `x-2`, …).
  - **Major (silent wrong credential):** multiple distinct bearer tokens collapsed onto one provider.
    Fixed: `planAuth` emits one provider per *distinct* token (single-token collections keep the tidy
    `<domain>` id; multiple disambiguate by secret, e.g. `<domain>-user-token`); each request's
    `authRef` resolves via a `providerFor` map.
  - **Major (silent gap):** `basic`/`oauth2` auth was dropped with no marker. Fixed: any non-bearer
    `authentication.type` now emits a `// TODO(migrate)` note and no false `authRef`.
  - **Major (inconsistency):** a top-level chained request got `__TODO_CHAIN__` with no comment (only
    suite nodes had one). Fixed: `requestExtras` centralizes the TODO notes for both tests and nodes.

  Simplicity reviewer confirmed the diff was already lean; applied the genuine wins: shared
  `INSOMNIA_VAR_TAG` + `STATUS_ASSERT` consts (dedup), single-pass `emitSuite` (source + mapping in one
  loop), `renderMigration` now `|`-escapes cell values (`mdCell`), and a `tagsHint` helper in the
  `generate_suite` prompt. Left as-is (low value): `golden.value()` vs `renderLiteral` scalar branch,
  `writeImport` sequential I/O. Gate re-run green: typecheck / lint / test (**362 passed | 37
  pg-gated skips**) / compile. Not fixed (parked): an `atp golden` live-capture CLI and importer
  sub-env/params handling (see `docs/deferred.md`); unsupported (non-HTTP) Insomnia items are still
  skipped silently — acceptable for a scaffolder, noted here.
