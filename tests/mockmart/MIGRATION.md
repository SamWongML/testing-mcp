# Migration — Insomnia → IR

Generated by `atp import fixtures/insomnia/mockmart.insomnia.yaml`, then finished by hand
(the `import_insomnia_collection` workflow). Insomnia YAML is a *source*, converted into the
typed IR. Track cutover here and retire the Insomnia file once the namespace reaches parity.

**Status: parity reached.** `atp validate` is clean and every entry passes against the
Mockmart fixture service (`fixtures/sut/mockmart-sut.ts`). The Insomnia export is kept only
as the provenance record for the table below.

## Running this namespace

The service and the runs read the same credential bag, so one export block configures both:

```bash
export ATP_SECRET_API_TOKEN=shopper-token-3f9a       # bearer, catalog + cart reads
export ATP_SECRET_ADMIN_TOKEN=admin-token-77b2       # bearer, order + payment writes
export ATP_SECRET_SEARCH_KEY=search-key-c410         # apiKey header  (x-api-key)
export ATP_SECRET_FEATURED_KEY=featured-key-2d61     # apiKey query   (api_key)
export ATP_SECRET_LEGACY_PASSWORD=legacy-pass-d88e   # basic          (qa-bot:…)
export ATP_SECRET_OAUTH_CLIENT_SECRET=oauth-secret-91ac  # oauth2 client credentials
export ATP_SECRET_QA_PASSWORD=qa-password            # the login param default

pnpm exec tsx fixtures/sut/mockmart-sut.ts --port 8899 &
pnpm atp run mockmart.smoke --base-url http://127.0.0.1:8899 --report html
```

`--base-url` is not optional here: without it `atp run` starts the built-in mock SUT, which
serves the sample corpus's routes, not Mockmart's.

## What the transform did, and what finishing it required

The scaffolder emitted 15 files and 21 mapping rows; `atp validate` then reported **27
violations** — 8 unwired `__TODO_CHAIN__` placeholders and 19 nodes whose only assertion was
the non-pinning `status lt 500`. Closing them:

- **Chains wired (8).** `extract` on the source node + `{{nodes.<id>.<var>}}` downstream plus
  an explicit `needs` edge. In `order-lifecycle` the three reads/writes on the created order
  are siblings, so they address `{{nodes.create-order.orderId}}` rather than `{{vars.*}}`,
  which is last-writer-wins across parallel branches.
- **Auth completed (4 providers).** `atp import` maps only `bearer`; the collection's
  `basic`, both `apikey` placements, and `oauth2` client-credentials became declarative
  `AuthProviderSpec`s in `tests/_shared/auth/`, each carrying a `{{secrets.*}}` template.
- **Assertions strengthened (19 nodes).** `atp golden <id> --base-url …` captured a baseline
  per node; the placeholder was replaced by the captured status plus shape checks, then
  tightened to exact values wherever the service is deterministic (`totalCents`, `itemCount`,
  the region/tier pricing rule).
- **Env pruned.** `password` → `{{secrets.QA_PASSWORD}}`; `region`/`tier` → the
  `search-catalog` matrix; `searchTerm`/`slowMs` → params; `legacyUser` → the basic provider.
  Only `baseUrl` and `productId` are still addressed as `{{env.*}}`.
